# Abzeichen

Sieben Abzeichen für den Kurs, dazu drei Bonus-Abzeichen. Du hakst sie selbst ab,
wenn die Bedingung stimmt: `[ ]` wird `[x]`. Der Agent zeigt dir am Ende jedes
Kurstags den Stand. Mit `git push` sieht auch die Lehrperson, wie weit du bist.
Es gibt keine Punkte für Tempo: Wer gründlich lernt, kommt genauso ans Ziel.

| | Abzeichen | Bedingung |
| --- | --- | --- |
| [ ] | **Führerschein** | Die vier Stationen in `kurs/sicherheits-fuehrerschein.md` ausprobiert und die Fragen am Schluss beantwortet. |
| [ ] | **Erste Sitzung** | Eine Lernsitzung mit einem Ablauf bis zum Journaleintrag durchgespielt. |
| [ ] | **Gebaut** | Ein eigener oder angepasster Ablauf unter `skills/` startet mit «starte» und seinem Namen. |
| [ ] | **Selbst gelernt** | Mit dem eigenen Ablauf eine ganze Sitzung am eigenen Stoff gelernt. |
| [ ] | **Getestet** | Eine andere Person hat deinen Ablauf ausprobiert, ihre Rückmeldung steht in deinem Journal. |
| [ ] | **Vorgestellt** | Den Ablauf in zwei Minuten vorgestellt. |
| [ ] | **Hochgeladen** | An allen drei Kurstagen ohne Fehler gepusht. |

## Bonus

| | Abzeichen | Bedingung |
| --- | --- | --- |
| [ ] | **Retter** | Eine kaputte Datei mit `git restore` zurückgeholt, ausserhalb der Übung. |
| [ ] | **Übersetzer** | Den eigenen Ablauf auf ein zweites Fach übertragen. |
| [ ] | **Fehlerjäger** | In einem Ablauf eine Stelle gefunden, die gegen seinen didaktischen Grundsatz verstösst, und sie verbessert. |
